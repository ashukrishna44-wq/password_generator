# Password Generator

A simple Python project that generates strong random passwords using letters, numbers, and symbols.

## Features
- Generate random passwords
- Choose password length
- Use uppercase and lowercase letters
- Include numbers and symbols

## Tech Used
- Python

## How to Run
1. Download or clone this repository
2. Open the project folder
3. Run the file:

```bash
python password.py
```

I created this project to practice Python and build a small cybersecurity-related tool.
